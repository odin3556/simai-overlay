# Discord 投稿用テンプレート

応募も要望も **Google フォームで受け付け**、Discord には Webhook で通知だけが届く運用です。
`{募集フォームURL}` と `{要望フォームURL}` を、`create-form.gs` 実行時にログに出た「回答用URL」に置き換えて貼ってください。

---

## 募集チャンネル用

```
📢 **simai-overlay 共同開発メンバー募集**

maimai の譜面（simai）を YouTube の手元動画に重ねて表示し、
ズレや配置をチェックできる Chrome 拡張を作っています。
動画から simai の下書きを作る機能も開発中です。

🙌 **こんな方を募集しています**
・一緒にコードを書いてくれる方（JavaScript / Chrome 拡張）
・動画で動作確認・不具合報告をしてくれるテスター
・simai の書き起こしをチェックしてくれる方

📝 **応募はこちらのフォームから**（3分ほどで終わります）
{募集フォームURL}

フォームでは次のものをお聞きします：
・Gmail アドレス（開発フォルダを Google ドライブで共有するため）
・Discord の表示名・ユーザー名・ユーザーID（連絡のため）

💡 ユーザーIDの調べ方
ユーザー設定 > 詳細設定 >「開発者モード」をオン
→ 自分のアイコンを右クリック（スマホは長押し）→「ユーザーIDをコピー」

※ このチャンネルへの書き込みでは応募を受け付けていません。必ずフォームからお願いします。
```

## 要望・不具合の案内（ピン留め推奨）

```
💬 **要望・不具合・質問はフォームから**

{要望フォームURL}

不具合の場合は
・何をしたら
・どうなって
・本当はどうなってほしいか
・YouTube の URL / 曲名 / 難易度
を書いてもらえると助かります 🙏

※ Discord への書き込みでは受け付けていません。届いた内容は管理者が一覧で確認しています。
```

## 承認した人への連絡用（DM など）

```
ご応募ありがとうございます！ 開発フォルダを入力いただいた Gmail アドレスに共有しました。
Google ドライブの「共有アイテム」から開けます。
```

## チャンネル構成の例

| チャンネル | 用途 | 投稿できる人 |
|------------|------|--------------|
| #お知らせ | 更新情報・募集と要望フォームの案内 | 管理者のみ |
| #フォーム通知 | Webhook の通知先（応募・要望・フォルダ共有） | Webhook のみ・**管理者だけ見られる** |
| #開発 | 共同開発メンバーの相談 | 「共同開発」ロール |

- `#フォーム通知` は応募者の情報が流れるので、一般メンバーには見えない設定にしてください。
- 応募と要望を別チャンネルに分けたい場合は、Webhook を2つ作って `RECRUIT_WEBHOOK_URL` / `REQUEST_WEBHOOK_URL` に入れます（README 参照）。
