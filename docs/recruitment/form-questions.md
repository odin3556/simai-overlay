# 募集フォームの質問一覧（手作業で作る場合）

`create-form.gs` を使えば自動で作られます。Google フォームの画面で手作業で作る場合や、内容を見直す場合はこちらを参照してください。

## フォーム名・説明

- **タイトル**: simai-overlay 共同開発メンバー募集
- **説明**:
  > maimai の譜面（simai）を YouTube 動画に重ねて確認する Chrome 拡張「simai-overlay」の共同開発メンバー・テスター募集フォームです。
  > ・開発用フォルダは Google ドライブで共有します。共有先は下で入力いただく Gmail アドレスです。
  > ・連絡は Discord で行います。Discord の名前と ID を正確に入力してください。
  > ・入力内容は開発メンバーの管理と連絡にのみ使い、第三者には公開しません。
- **送信後のメッセージ**: ご応募ありがとうございます！ 確認後、Discord でご連絡します。

## セクション1: 連絡先

| # | 質問 | 形式 | 必須 | 補足・回答の検証 |
|---|------|------|------|------------------|
| 1 | Gmail アドレス | 記述式 | ○ | 正規表現 `^[A-Za-z0-9._%+\-]+@gmail\.com$`。「開発フォルダをこのアドレスに共有します」 |
| 2 | Discord 表示名 | 記述式 | ○ | サーバーで表示されている名前 |
| 3 | Discord ユーザー名 | 記述式 | ○ | 正規表現 `^@?[a-z0-9_.]{2,32}$`。@ の後ろの英数字の名前 |
| 4 | Discord ユーザーID | 記述式 | ○ | 正規表現 `^[0-9]{17,20}$`。調べ方を説明に書く（下記） |
| 5 | GitHub アカウント（任意） | 記述式 | | |

**Discord ユーザーIDの調べ方**（質問4の説明文）
1. Discord の「ユーザー設定 > 詳細設定」で「開発者モード」をオン
2. 自分のアイコンを右クリック（スマホは長押し）→「ユーザーIDをコピー」

> 表示名・ユーザー名は変更できますが、ユーザーIDは変わりません。管理はIDを基準にすると確実です。

| # | 質問 | 形式 | 必須 | 補足 |

同意事項の選択肢:
- 入力した Gmail アドレスに開発フォルダが共有されることに同意します
- 入力内容が開発メンバーの管理・連絡に使われることに同意します
- 共有されたファイルや未公開の情報を許可なく外部に公開しません

## 回答シートに足す管理列

| 列 | 中身 |

## 修正タスクシート

同じスプレッドシートの別シート「修正タスク」。不具合の報告は自動で1行増え、要望はメニューから追加します。

| 列 | 中身 |
|----|------|
| タスクID | 不具合は `BUG-001`、要望は `REQ-001` から連番（自動） |
| ステータス | プルダウン: 未着手 / 対応中 / 確認待ち / 完了 / 保留 / 対応しない |
| 優先度 | プルダウン: 高 / 中 / 低（フォームの優先度から自動。未回答は「中」） |
| タイトル・種類・関係する機能・内容・動画・曲・報告バージョン・報告者 | フォームの回答から自動 |
| 担当 / 修正バージョン / 対応メモ | 手で記入 |
| 起票日 | 報告の日時（自動） |
| 完了日 | ステータスを「完了」にした日時（自動。完了以外に戻すと消える） |
| 元の報告 | 要望一覧の該当行へのリンク（自動） |
